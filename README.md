# NEO Arcana — Humans of Neoversity

Сайт-колода: 5 человек = 5 карт Таро. Клик по карте открывает профиль, внизу блок «Хто ми як команда» и финальная карта «Світ». Презентация 30.10.2026.

Стек: Vite + обычный JavaScript + CSS + GSAP. Без бэкенда, хостинг на Vercel.

## Запуск

Нужен Node 20+.

```
npm install
npm run dev              # на компьютере
npm run dev -- --host    # чтобы открыть с телефона (тот же Wi-Fi), адрес покажет терминал
npm run build            # сборка в папку dist
npm run preview          # проверить собранную версию
```

## Как редактировать контент

Весь текст лежит в одном файле: `src/data/team.json`. Код трогать не нужно.

| Поле | Что писать | Размер |
|---|---|---|
| `id` | короткое имя латиницей без пробелов, попадает в ссылку `#/card/<id>` | `olena`, `max` |
| `name` | имя (можно с фамилией) | |
| `arcana.number`, `arcana.uk` | римская цифра и название аркана (таблица ниже) | |
| `accent` | личный цвет свечения карты, hex | |
| `superpowerShort` | суперсила одной строкой на карте | до 40 знаков |
| `story` | история: откуда, что сформировало, один случай | 70–110 слов |
| `experience` | чем занимался до Neoversity | 150–300 знаков |
| `motivation` | почему Neoversity | 150–300 знаков |
| `goals` | цели на ближайшие годы | 150–300 знаков |
| `afterGraduation` | где вижу себя через 3–5 лет после выпуска | 1–2 предложения |
| `superpower` | что могу дать другим | 1–2 предложения |
| `links` | необязательно: `[{"label": "LinkedIn", "url": "https://..."}]` | можно оставить `[]` |

Тексты на сайте украинские. Кавычки в JSON только двойные `"`, внутри текста используйте «ёлочки». После правки проверьте, что файл остался валидным JSON (редактор подчеркнёт ошибку).

Блок команды: `team.cards` (4 карточки). Блок «Про нас» (`#about`): top-level `finale` (numbers, skills, paragraphs).

## Картинки

| Что | Куда | Формат |
|---|---|---|
| Карта (иллюстрация) | `public/assets/cards/member-N.webp` | WebP, пропорции 2:3, до 1000×1500, до 160 КБ, **без текста на картинке** |
| Портрет для профиля | `public/assets/portraits/member-N.webp` | WebP, до 1200×1500, до 220 КБ |

Если переименуете файлы, поменяйте пути в `team.json`. Пока файла нет, сайт показывает заглушку с логотипом и инициалами. Конвертировать в WebP удобно на squoosh.app (качество 75–80).

## Публикация (GitHub → Vercel)

1. Создайте на github.com новый репозиторий (например `neo-arcana`), пустой, без README.
2. В папке проекта:
   ```
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/neo-arcana.git
   git push -u origin main
   ```
3. На vercel.com войдите через GitHub → **Add New → Project** → выберите репозиторий.
4. Настройки проекта (Vercel сам подставит Vite; если нет — выставьте вручную):

   | Setting | Value |
   |---|---|
   | Framework Preset | **Vite** |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Install Command | `npm install` (по умолчанию) |
   | Root Directory | `.` (корень репозитория) |
   | Node.js Version | **20.x** (в Project Settings → General) |

5. Нажмите **Deploy**. Каждый новый `git push` в `main` автоматически обновляет сайт. Ссылку вида `neo-arcana.vercel.app` можно превращать в QR-код.

Маршруты профилей — это hash (`#/card/<id>`), отдельные rewrite-правила на Vercel **не нужны**. Файл `vite.config.js` уже с `base: './'`, для деплоя в корень домена этого достаточно.

После первого деплоя, если превью в соцсетях важно: в `index.html` у `og:image` и `twitter:image` можно заменить относительный путь на абсолютный URL вида `https://<ваш-проект>.vercel.app/assets/og/og-cover.svg` (или PNG 1200×630). На сам сайт это не влияет.

## Запасной вариант на презентацию

Сделайте все три, не один:

1. **Запись экрана**: 1–2 минуты прокрутки сайта, открытие карт, блок «Про нас». Лежит на ноутбуке и на телефоне.
2. **Локальный запуск**: на ноутбуке выполнить `npm run build`, затем `npm run preview`. Работает без интернета. Двойной клик по `dist/index.html` не сработает (браузер блокирует модули при открытии файла).
3. **Скриншоты** каждой карты и профиля в одной папке.
